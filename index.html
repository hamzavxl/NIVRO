NIVRO reinstall.sh
GitHub Repository

Unattended OS Provisioning Engine

reinstall.sh is an automated operating system bootstrapper for KVM, Xen, Hyper-V, and bare-metal servers. It boots an in-memory installer via kexec, preserves existing static network routes, and writes clean Linux or Windows images without manual VNC intervention.

Installation

Run the bootstrapper on a target root shell using a generated deployment payload:

bash — root@host 
curl -sSL https://hamzavxl.github.io/NIVRO/reinstall.sh | bash -s -- --payload <PAYLOAD-HASH>
Parameter Policy: Direct CLI flags (such as --password, --key, or --image-name) are disabled. Target OS selection, credentials, and port bindings are passed exclusively inside the signed --payload hash.

Technical Overview

In-Memory Boot (kexec)

Downloads a minimal initramfs environment into RAM and switches kernels directly via kexec, avoiding external ISO mounts or IPMI consoles.

Static Network Preservation

Reads active IPv4 addresses, CIDR prefixes, and default gateway routes from the host interface before formatting and applies them to the new OS.

VirtIO Storage & Network

Injects Red Hat paravirtualized drivers (viostor, vioscsi, and NetKVM) into WindowsPE and target system hives during deployment.

Automated Partitioning

Configures GPT (UEFI) or MBR (Legacy BIOS) partition tables automatically and expands the target system image across the primary block device.

Execution Sequence

1. Payload Validation
Verifies the cryptographic HMAC signature of the --payload hash and extracts target parameters.
2. Environment Probe
Checks hypervisor compatibility, detects primary block storage, and records active IPv4/Gateway configuration.
3. RAM Installer Load
Prepares the unattended answer file, injects required hypervisor drivers, and reboots into the in-memory installer.
4. Disk Write & Boot
Formats the primary drive, writes the target operating system image, applies network settings, and boots into the new OS.

System Requirements

Privileges
Must be executed as root (or Administrator) on the target host.
Virtualization
Requires full hardware virtualization (KVM, Xen, Hyper-V, VMware, or Bare-Metal). Containerized environments (OpenVZ / LXC) are not supported.
Storage Warning
Reinstallation repartitions the primary disk and permanently erases all existing data. Back up critical files prior to execution.
