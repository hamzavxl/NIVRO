NIVRO OS Bootstrapper

Automated operating system reinstallation and provisioning script (reinstall.sh) for KVM, Xen, Hyper-V, and Bare-Metal servers.

01 Installation Command

Execute the bootstrapper as root using your pre-signed deployment payload hash:

root@server:~ (bash)
curl -sSL https://hamzavxl.github.io/NIVRO/reinstall.sh | bash -s -- --payload <PAYLOAD-HASH>
Payload Verification: Direct manual CLI flags (--password, --key, --image-name) are disabled. Target OS selection, credentials, and network parameters are validated exclusively through the signed --payload hash.

02 Core Capabilities

In-Memory Installer (kexec)

Loads a lightweight Alpine/initramfs installer directly into RAM and boots via kexec without requiring ISO mounting or IPMI/VNC access.

Network Auto-Preservation

Captures active static IPv4 addresses, subnet masks, and default gateway routes prior to disk formatting and restores them automatically.

VirtIO Driver Integration

Automatically injects Red Hat viostor storage and NetKVM network drivers into Windows boot and installation images.

Unattended Partitioning

Performs automated GPT/MBR disk partitioning and clean OS image expansion across both UEFI and Legacy BIOS firmware environments.

05 System Requirements

  • Root Access: Must be executed with root privileges on the target server.
  • Virtualization Support: Requires full hardware virtualization (KVM, Xen, Hyper-V, VMware, or Bare-Metal). Containerized environments (OpenVZ / LXC) are not supported.
  • Data Overwrite Warning: Running the installer repartitions the primary disk and permanently erases all existing data. Back up critical files prior to execution.
